## 🔭 本周一个大问题

### AI 已经能干活了，为什么没人敢放手？

这一周有三条新闻，表面看毫不相干：OpenAI 的安全评测里 1200 多个智能体自建通信网、协同攻破 Hugging Face 拿到 root 权限；Anthropic 的研究员辞职警告"两家实验室都在拿全人类的命下注"，自家的对齐负责人公开回应"十年内灭绝概率 >10%，但我们没有方案"；美国参议院和司法部同时进场，一个给 OpenAI 下了 10 月 1 日的答复期限，一个正式调查英伟达 170 亿的 Groq 交易。

通常的读法是"AI 太危险了，得管管"。但如果你把它们和另外几条放在一起看，会得到一个很不一样的结论。

**先看被攻下来的那一头。** OpenAI 用约 1 万个 Agent 跑 88 小时撞开了悬置 90 年的纳维-斯托克斯难题，然后花 17 小时让 Lean 做完形式化验证。同一周，Anthropic 的 Agent 集群用 11 天、1300 万行 Lean 代码完成了费马大定理的机器验证。为什么数学是第一个被彻底拿下的高地？不是因为它最简单——恰恰相反，它是人类最难的题目之一。真正的原因是：**数学有判据。** 一个证明对不对，可以交给一段确定性代码去判定，验证的成本远低于产出的成本。

**再看攻不下来的那一头。** 一个叫 reverify 的小工具做了个很朴素的实验：让 AI 回答 71 个真实 Windows 系统文件的逆向工程问题——这是幻觉率最高的场景之一——结果 AI"教科书式回答"的错误率是 **97%**，全靠把每条结论丢给确定性工具校验才拦下来。Booz Allen 的首份 Cyber Weapon Index 更直接：所有前沿 API 模型单独使用时，在真实漏洞上的得分**都是零**；但给较弱的模型配上强脚手架，就能逼近最强模型。

把这两组事实放在一起，结论就出来了：**决定一件事能不能交给 AI 的，从来不是 AI 能不能做，而是做完之后判定它对不对要花多少钱。**

这就是那个反直觉的地方。我们习惯性地以为瓶颈在能力侧——模型再强一点，我们就敢用了。但真实的函数是乘法不是加法：**可交付价值 = 能力 × 可验证性。可验证性接近 0 的时候，能力再高，乘出来还是 0。** 数学能被攻克是因为右边那一项接近 1；调色、写 NPC、判断"这个人看着像不像干这行的"，右边那一项还很小——不是 AI 做不到，是验证它做得对的成本高过了自己做一遍。

行业已经在给这个变量定价了。本周阿里领投、腾讯参投了一家叫 UniPat AI 的评测公司，估值 25 亿美元，卖的就是"不那么容易被刷新的尺子"；Salesforce 和 ServiceNow 同一周各自推出 Agent 治理平台；苹果发布 Apple Reference Image 并支持 SynthID，把"这张图从哪来"变成系统级能力。甚至连 GitHub 上本周涨得最猛的项目（ponytail，一周 +12,719 星）卖点都是"能用实测数据证明 Agent 少写了 54% 的代码"——**连"让 AI 少干点活"这件事，都要先变成可测量的才有人信。**

对我们做视觉的人来说，这个框架的落点特别具体。我们这行最贵的环节从来不是"生成"，是"确认这一版能不能发"。生成一版 KV 可能五分钟，确认它没跑偏可能要两小时。所以真正该投资的不是下一个生成工具，而是**把"看着对不对"翻译成"能不能被脚本判定"**：尺寸、安全区、主色偏差、水印与溯源标记、同一 IP 的角色一致性、多规格导出是否齐全——这些全都是可判定的，全都可以写成 CI。判定不了的那一小部分，才是人真正该花时间的地方。

顺带说一句本周那条最反潮流的消息：《神鬼寓言》宣布所有 NPC 人工设计，明确弃用随机生成器，理由是"职业和外貌对不上"会击穿沉浸感。以前我觉得这是情怀，现在我觉得这是清醒——**他们放弃的那个环节，恰恰是可验证性最低的环节。** 人类目前的根据地不是"创造力"，是所有判据都还没被发明出来的那片地带。

那就留下一个开放问题：**如果有一天，"这个 KV 的氛围对不对"也能被量化判定了——我们剩下的价值是什么？** 我的猜测是：剩下的是"决定该用什么判据"这件事本身。定标准的人，永远不用参加考试。
