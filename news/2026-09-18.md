## 💡 AI 效率技巧

### 🟢 [给子 agent 加 `omitClaudeMd: true`：10 个子 agent 输入上下文从 226,340 降到 26,480 tokens](https://agihunt.info/en/p/1a0ad19184d67b9931785dcef49?campaign_id=daily-2026-09-18)
**来源**：Claude Code 用户实测 [🐦 X/KOL] [🟨 T2] | **时间**：9/18
对不需要项目指令的子 agent 加 `omitClaudeMd: true`，10 个相同子 agent 的输入上下文从 226,340 tokens 降到 26,480（约 -88%）。⚠️ 这不提高使用上限，只是阻止 CLAUDE.md 被加载进每个子 agent。

### 🟢 [更隐蔽的配额泄漏是缓存 TTL：子 agent 默认只有 5 分钟](https://agihunt.info/en/p/1a0b13458ab027e289575fc42a7?campaign_id=daily-2026-09-18)
**来源**：用户实测 [🐦 X/KOL] [🟨 T2] | **时间**：9/18
子 agent 的 prompt 缓存默认 TTL 是 5 分钟（主对话为 1 小时）。任何超过该时长的工具调用（测试、构建、git hooks）都会让缓存过期，下次请求以 1.25× 价格重写完整上下文。有用户测出每个子 agent 300k–600k tokens，五个子 agent 一天跨 26 次重写产生 1220 万写入 tokens；**一行配置削减缓存写入约 75%**。

### 🟢 [Mollick 用法：让 orchestrator 开 18 个并行线程，配一个专职 skeptic 做事实核查](https://agihunt.info/en/p/1a0b0d1f5353749ac17e22b3f78?campaign_id=daily-2026-09-18)
**来源**：Ethan Mollick [🐦 X/KOL] [🟨 T2] | **时间**：9/18
用 Claude Projects 当"专家组织"跑：用户只跟 lead orchestrator 对话，后者混合贵/便宜专家 agent；筛选历史谜题后开 18 个并行线程，每个线程内再派生子 agent 做模拟与密码分析，草稿经写作 agent 与一个**专门的 skeptic agent** 做事实核查，整体运行约一天。

### 🟢 [「资历悬崖」：跳过苦工期的人，会失去识别"看似合理但错误"输出的能力](https://agihunt.info/en/p/1a0b06f2a0bbf6d4a6b47b9e20a?campaign_id=daily-2026-09-18)
**来源**：Reddit 长文 [🐦 X/KOL] [🟥 T3] | **时间**：9/18
一篇被广泛讨论的文章提出：初级工程师那几年"苦工"本质是认知学徒期——花几天追内存泄漏、清洗脏数据，教的是失败模式长什么样。跳过这些摩擦，新人缺少识别"看似合理但错误"输出的疤痕组织，调试能力会萎缩。担忧是 5–10 年后系统级直觉的空心化。⚠️ 观点类内容，非事实报道。

## 🔭 编辑观察

**今天最值得记住的，不是任何一个数字，是"披露"本身变成了竞争动作。**

OpenAI 昨天公开 6 起模型异常行为，Anthropic 今天公开 26% 的 R&D 自动化率。两家在 48 小时内先后把最容易被攻击的内部数据摆到台面上——这不是巧合，是在查理三世峰会和"该不该降速"的舆论场里抢定义权。**谁先给出可外部验证的指标，谁就握住了"什么算安全"的尺子。**

但要读得仔细一点。Anthropic 的 26% 有明确边界：CL4 是"主导"，不是"自主"；没有任何一个子集处于 AL5；3 万个 agent 的每一个动作都被前置检查。可同一份报告里也写着模型与人类评级一致率只有 59%——而人类彼此之间只有 35%。**这既说明自动化的速度是真的，也说明这套尺子本身的精度有限。** 读这类数字，别只记百分比，要看分母和测量方法。

华为昇腾 960 是另一条线。用 5500 个 NPO 光模块替代 4.8 万颗 800G 光模块、把功耗砍掉 550 千瓦——**这是典型的系统级创新绕开单点工艺限制**。在制程受限的前提下，这条路比堆芯片现实得多。对做内容的我们，它的落地含义很朴素：国内推理单价还会继续掉，批量生成素材的成本曲线还没见底。

**今日剔除说明**：一条"GPT-6 Astra 自主破译 1941 年德军未解 Enigma 密文"的病毒式传播线程，以及一条"OpenAI 接近 Hodge 猜想"的 Reddit 爆料，均只有社交平台截图、无官方确认、无预印本、无 Tier 1 媒体报道。按反投毒规则，前者**不予收录**，后者仅作为市场情绪（Polymarket 57%）记录并降级为传闻。宁可漏报，不可误报。
