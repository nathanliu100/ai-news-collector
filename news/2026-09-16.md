**来源**：Google 官方博客 + SiliconANGLE [🏢 官方] [🟩 T1] | **时间**：2026-09-15 | ✅ 已验证：blog.google 官方发布 + SiliconANGLE 独立报道 + 腾讯新闻（智通财经）跟进

### 🔴 [生数科技发布 Vidu S2：视频可以边播边改，实时换风格/换装/换人/换背景](https://vidu.com/vidu-stream)
**来源**：生数科技官方 + arXiv 技术报告 [🏢 官方] [🟩 T1] | **时间**：2026-09-15 | ✅ 已验证：arXiv:2609.11638 技术报告 + vidu.com 官方体验入口 + 量子位/网易科技独立报道

距 S1 仅 **69 天**，Vidu S2 发布即全量开放。两个模型：**S2-Editing** 对正在播放的视频流做实时编辑——换风格、虚拟试穿、换角色、换背景，靠"帧对齐稀疏注意力"让每一帧锁死原视频同一时刻，动作轨迹不穿帮；**S2-Avatar** 从 540P 升到 **720P、25-42 FPS**，可在生成途中随时递入新的参考图（杯子、衣服、场景），并由 VLM Agent 持续检查画面、维护"手持杯子"这类状态。核心技术 Self-Replay Forcing（SRF）：先让模型按真实推理方式生成长视频，再从自生成轨迹采样加噪做因果回放，**让模型学会接住自己的误差**。评测：S2-Avatar 在 StreamAV-Bench 九项指标全部第一（主体一致性 0.998）；S2-Editing 在 Sparkle-Bench 综合 3.74、OpenVE+RefVIE 联合评测 4.26，均超对比的离线模型 Bernini-R 14B。另外还探索了**空间视频**：实时生成或编辑后转为左右眼画面送进 VR 头显。 [💎 部门相关] [🎯 重点工具]

> 📰 **故事线**：Vidu 实时视频 69 天一代
> 7/3 S1 论文（540P 实时对话）→ 9/10 S2 论文 → **9/15 S2 发布并全量开放体验**

<!-- crew:elon -->69 天一代不是卷，是架构选对了。**SRF 让模型在带误差的自生成历史里训练，这一步把"流式生成"从演示变成了工程**。谁先解决长时漂移，谁就拿下直播和虚拟拍摄这两个现金场景。<!-- /crew -->
<!-- crew:jobs -->真正的拐点不是 720P，是"发布即开放"。**大多数公司把实时视频当稀缺资源放内测名额，生数直接全量放开**——它赌的是真实使用场景回馈数据的速度比竞品的技术领先更快。<!-- /crew -->
<!-- crew:wanweigang -->注意那个 0.998 的主体一致性。**这个数字漂亮到我反而想看它在失败案例里是什么样**——一致性指标接近 1 往往意味着评测集不够难，而不是模型已经解决问题。要看用户在真实直播间里递进去的奇怪参考图。<!-- /crew -->
<!-- crew:tim -->帧对齐稀疏注意力这个设计是对的，但我想看长镜头。**切风格、换装在 10 秒片段里好看不难，难的是 5 分钟里光源方向始终自洽**——虚拟拍摄真正卡的是长时一致性，不是单帧效果。<!-- /crew -->
<!-- crew:mrbeast -->换装这个功能，直播电商等了三年了。**观众弹幕说"想看主播穿恐龙服"，下一秒真穿上——这是把观众从旁观者变成导演**，互动率会爆。<!-- /crew -->

## 🔭 编辑观察

今天真正值得记住的，不是任何一个模型发布，而是**"语音"这条线在同一天被两家从两个方向同时推进**：Google 把 Gemini 3.8 Live 塞进 Workspace 和 Search，解决的是"让语音 agent 在企业里落地"；阶跃把 StepAudio 3 五款模型一次性铺满，解决的是"让中文开发者一次拿到完整语音栈"。但两家的评测数据也同时暴露了同一件事——语音质量榜单的第一名（82.6）和银行任务完成率的三分之一（35.1%）长在同一个模型身上。**"听起来像人"这件事已经被解决得差不多了，"办得成事"还差得很远。** 行业正在把大量资源投向前者，因为它更容易做成漂亮的 demo。

第二件事是 **AI 安全从"企业自愿"走到了"企业主动要求被立法"**。Lehane 那句"不需要反垄断豁免"是今天信息密度最高的一句话——它意味着三家实验室的法务已经判断，协调的政治收益大于法律风险。但 POLITICO 那篇报道里 Berkeley 教授 Recht 的质疑同样锋利：**如果第三方评估机构和被评估的实验室来自同一批博士项目、同一套世界观，那独立性就是个装饰。** OpenAI 自己都说"评估机构必须被看成独立于我们"，说明它也知道这个问题。真正的看点不是标准机构会不会成立，而是**谁给它付钱、谁能否决它的人选**。

第三，**国内的设计/素材工具正在往"实时"这个方向扎堆**。Vidu S2 的 69 天迭代、Lovart 的多机位合成、Viggle 的三步换角色，共同点是都在压缩"从想法到看见结果"的延迟。对做推广素材的团队来说，这意味着**素材生产正在从"批处理"变成"交互式"**——以前是生成 20 条挑 1 条，以后可能是一边调一边看。这个工作方式的变化，比任何一次模型跑分都更影响我们每天怎么干活。

最后一个观察：今天 GitHub Trending 前五几乎全是 **agent 治理层**（给 agent 用版本控制的 atlas、给 agent 定规范的 agent-skills、把编码 agent 变研究 agent 的 OpenResearch），没有一个是新模型。**当生态开始围绕"怎么管住 agent"造工具，说明 agent 已经度过了能不能用的阶段，进入了怎么用的阶段。**
