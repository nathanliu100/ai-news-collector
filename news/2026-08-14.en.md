## 🧪 Model Releases & Updates

### 🔴 [Google launches Gemini 3.7 Flash: coding & agent leap, price halved](https://blog.google/technology/ai/)
**Source**: Google official blog [🏢 Official] [🟩 T1] | **Time**: 8/13 (ET) | ✅ Verified: Google blog + Ars Technica (T1)
Three weeks after Gemini 3.6 Flash, Google ships the "workhorse" Gemini 3.7 Flash, tuned for coding and agent tasks. Official numbers: FrontierCode 1.1 Main 34.4%→43.6%, DeepSWE v1.1 49%→65.3%, WebDev Arena Elo 1538→1588, GDP.pdf 22%→34%, AutomationBench 17%→30.4%. To counter OpenAI's price cuts, Google offers an introductory price through year-end: $0.75/$3.75 per million tokens (half of 3.6 Flash), rising to $1.5/$7.5 in 2027. It now powers Gemini Spark (AI Pro/Ultra only); the regular chat UI still runs 3.6 Flash. The flagship Gemini 3.5 Pro remains delayed — "soon," says Google.
> 📰 **Storyline**: Gemini release cadence
> May I/O promised 3.5 Pro in June (missed) → 3.6 Flash three weeks ago → **8/13 3.7 Flash (Pro still delayed)**

### 🔴 [DeepSeek open-sources Harness (DSH): 24k stars in 1.5h, a GitHub record](https://github.com/deepseek-ai/deepseek-harness)
**Source**: GitHub repo deepseek-ai/deepseek-harness [🏢 Official] [🟩 T1] | **Time**: 8/13 night | ✅ Verified: official GitHub repo (Trending #1) + independent media
DeepSeek releases DeepSeek Harness (DSH) developer preview under MIT — its self-built agent runtime that connects LLMs to filesystem, terminal, web, code tools, and other agents, handling context, tool calls and task execution. "Everything is a plugin" (driven by Cordis): model, tools, skills, session, sandbox, storage, loops, scheduling, and UI are all swappable. Supports Web UI / TUI / Headless and multi-agent collaboration. ~1.5 hours after release it passed 24k stars — the fastest star growth in GitHub history (+16,547 today, Trending #1). This marks DeepSeek's move from "base models + API" into the AI-coding execution layer contested by Claude Code and Codex.
> 📰 **Storyline**: DeepSeek's execution-layer push
> 8/13 V4 Pro GA (agent boost) → **8/13 night Harness open-sourced (fills the "execution layer" gap)**

### 🔔 [OpenAI developing "Astra" long-horizon multi-agent model family](https://www.theinformation.com/)
**Source**: The Information [📰 Media] [🟩 T1] | **Time**: 8/14 | 📡 Rumor, unconfirmed
Per The Information (three sources), OpenAI is building an "Astra" model family to tackle longer, more complex tasks by coordinating multiple agents working for hours or days. ### 🟡 [Claude rolls out invisible watermarking across all AI-processed content](https://new.qq.com/rain/a/20260814A000SS00)
**Source**: Anthropic support docs [🏢 Official] [🟩 T1] | **Time**: 8/14
To comply with the EU AI Act's content-labeling rules, Anthropic will watermark everything its models process (not just generate). Text outputs get invisible watermarks via token-choice biasing; other files get C2PA provenance metadata. Anthropic took a blanket approach — even minor edits get marked, though the EU law exempts "auxiliary standard editing." Critics note the watermark is easily stripped yet can unfairly burden honest users. [💎 Dept]
