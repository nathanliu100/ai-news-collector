### 🔴 [OpenAI 宣布用 AI 解决纳维-斯托克斯问题：约 1 万个 Agent 协同 88 小时，Lean 验证 17 小时](https://openai.com/index/navier-stokes-solution/)
**来源**：OpenAI 官方页面 + WSJ / Yahoo Tech / Firstpost [🏢 官方] [🟩 T1] | **时间**：9/8 美东 | ✅ 已验证：openai.com 官方页面 + 华尔街见闻 + 新华社系媒体多源
OpenAI 于 9 月 8 日公开一项由内部 AI 系统产出的数学成果：**纳维-斯托克斯存在性与光滑性问题**（2000 年提出的七大千禧年大奖难题之一，悬置约 90 年，历史上仅有一个千禧年难题被解决过）。OpenAI 称所用内部模型"显著强于 GPT-6 Astra"。做法是让**约 1 万个 Agent 并行、耗时约 88 小时**产出解析证明，再由 GPT-6 Astra 花 17 小时完成 Lean 形式化验证，发布了一份 165 页证明。结论方向是"证否"：一个初始光滑的静止流体，在外力光滑且总能量始终有限的前提下，可以在有限时间内发展出奇点（流速无限增长）——证明靠设计一个向内旋转拉伸的涡流实现。全项目 Agent 累计发 490 万条消息、消耗约 3000 亿输出 token，其中纳维-斯托克斯单项 270 万条消息、约 1300 亿 token。此前近 100 个 Agent 用约 50 小时先证伪了无外力版本的欧拉正则性问题。**OpenAI 明确表示不打算申领 100 万美元奖金**。争议同步发酵：NYU 数学教授 Tristan Buckmaster 与 Anthropic 研究员 Levent Alpöge 前一日刚发布带外力欧拉方程的成果，质疑 OpenAI 是听闻风声后才把资源转向"外力驱动"路线；OpenAI 称未接触对方工作，但承认"无法完全排除去标识化用户数据对模型的影响"。Fields 奖得主 Timothy Gowers 表示尚未读完证明，但称结果"不可否认是一个重大时刻"。

<!-- crew:jobs -->165 页的证明加上 Lean 验证，**有意思的是 OpenAI 主动放弃那 100 万奖金**——他们要的不是这道题的解，是"我们能解题"这件事本身被看见。<!-- /crew -->

### 🔴 [OpenAI 发布 ChatGPT Images 2.5：延迟最高降 50%，新增 Sketch 草图与图内评论精准改图](https://insideai.news/news/ai-tools/chatgpt-images-2-5/9943)
**来源**：OpenAI 官方发布 + Inside AI / Axios 提前体验 / IT之家 [🏢 官方] [🟩 T1] | **时间**：9/8 美东（北京时间 9/9）| ✅ 已验证：OpenAI 官方发布 + 多家独立媒体报道 + Axios 实测
OpenAI 发布 ChatGPT Images 2.5，官方称是其当前最先进的图像生成模型。相比 2026 年 4 月的 Images 2.0，**生成延迟最高降低 50%**，同时在细节锐度、自然光照、纹理丰富度上均有提升。三个关键能力升级：① **参考保真度**——把熟悉的人物、宠物放进不同场景/风格/构图时，外貌特征保持得更稳，直击"改一次就变脸"这个老痛点；② **多轮编辑一致性**——连续修改时记住前面的改动，后续调整建立在上一版基础上而不整张重生成，避免多次编辑后细节退化；③ **图内评论**——可以直接在图上圈位置下指令（"删除此区域""把这个改成蓝色"），模型只改指定区域。功能侧新增 **Sketch**（输入 `@Sketch` 后在对话里直接画草图，再补风格描述让模型补全）、海报/商品图等常见格式的**模板库**、以及分享图片时附带原始提示词供他人 remix。API 端拆成两档：**GPT-Image-2.5 Flare**（默认档，质量优于 GPT-Image-2 且延迟低 50%，适合创作者内容、社媒、产品体验、视觉搜索、快速原型、高批量生成）与 **GPT-Image-2.5 Sunburst**（更精细的编辑控制，成品级营销素材与精修产品图，生成时间更长）。支持 1024×1024 至 3840×2160（4K 横向），单边最长 3840 像素。安全侧延续 C2PA 元数据与隐形水印。已向全部层级的 ChatGPT、ChatGPT Work 与 Codex 用户开放（桌面/移动/网页）。OpenAI 披露：用户目前每周通过 ChatGPT Images 与 API 中的 GPT-Image 模型创建**超过 30 亿张图片**。 [💎 部门相关] [🎯 重点工具]

### 🟢 [reverify：把 AI 的每条"断言"交给确定性工具验证，逆向工程场景拦截率 100%](https://quidproquo.cc/posts/daily/2026-09-09-ai-agent-github-digest)
**来源**：GitHub + AI Agent GitHub Digest [🏢 官方] [🟩 T1] | **时间**：9/9
`2akouwu/reverify`（Python / MIT / ⭐1,036）是一个 MCP server + CLI，核心思路很朴素但有效：**不让模型自己断言，把每条关于代码或二进制的结论都丢给确定性工具验证，只有通过的才算数**。作者选了幻觉率最高的场景做基准——二进制逆向工程：71 个真实 Windows 系统文件上，AI 的"教科书式回答"错误率高达 **97%**，reverify 全部拦截，且没有误放行过任何一条错误声明（同一套 CI 在 Linux、macOS 与独立 aarch64 环境重跑验证）。附带 rollover 功能：把长任务交接给文件再开新 session，取代容易失真的自动摘要，兼容 Claude Code、Codex、Gemini CLI、OpenCode。`pip install reverify` 后接现有 MCP client 即可。

> 💡 **可迁移的思路**：这条不是"又一个 Agent 工具"，而是一个通用的工作法——**让 AI 负责提想法，让确定性脚本负责验收**。我们做批量素材时同样适用：AI 出图，脚本校验尺寸/水印/主色/安全区，不合格直接打回，而不是靠人眼过。
